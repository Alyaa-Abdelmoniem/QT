# Task 2 - Splash Screen and Home Screen

## Description
This project demonstrates a simple Splash Screen followed by a basic Home Screen using Qt Quick (QML).

## Features
- Displays a splash screen at application startup.
- Shows a loading indicator.
- Automatically switches to the Home Screen after 3 seconds.
- Simple and clean Home Screen interface.

## Tools Used
- Qt Creator
- Qt Quick (QML)

## How to Run
1. Open the project in Qt Creator.
2. Build the project.
3. Run the application.

## Output
The application starts with a splash screen, then automatically navigates to the home screen after three seconds.
