# Student Profile App (Qt Quick)

A simple Qt Quick application that displays a student profile using QML properties.

## Features
- Welcome card
- Student information card
- Built using Qt Quick Controls
- Simple static interface

## Technologies
- C++
- Qt 6
- Qt Quick
- QML
- CMake

## Project Structure

task1/
├── CMakeLists.txt
├── main.cpp
├── Main.qml
├── README.md
└── screenshots/

## Output

The application displays:
- Student name
- Major
- University
- City
- Email
