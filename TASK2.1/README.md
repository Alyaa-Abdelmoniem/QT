# Task 2 - Splash Screen

## Description
This project demonstrates a simple Splash Screen using Qt Quick (QML).

## Features
- Splash screen displayed when the application starts.
- Displays a logo image.
- Shows a loading indicator.
- Automatically switches to the Home Screen after 3 seconds using a Timer.

## Technologies
- Qt Creator
- Qt Quick (QML)

## Output
The application starts with a splash screen, then automatically opens the home screen after three seconds.
